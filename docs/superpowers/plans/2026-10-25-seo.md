# Commonplace SEO Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline implementation. Steps use checkbox syntax for tracking.

**Goal:** Make the public journal reliably readable, shareable and discoverable by search engines.
**Architecture:** Keep the journal UI as a hydrated component with server-supplied entries; add server-rendered permanent entry pages and explicit crawl routes. Use D1 as the single content source.
**Tech Stack:** Existing Vinext/React/D1; next-seo 7.3.0, schema-dts 2.1.0.
**Spec:** docs/superpowers/specs/2026-10-25-seo.md

## Global Constraints
- Preserve public access, anonymous posting, existing data, ivory journal design.
- Never serialize author cookies, deletion hashes or moderation records into public pages.
- Only actual entries appear in sitemaps and structured data; sample content is labeled and excluded.

## Review Focus
- Deleted and malformed entry URLs must return 404.
- User text cannot break JSON-LD, HTML or XML.
- Pagination must not omit entries sharing a timestamp.
- Empty databases must remain a usable, honest journal.
- Canonicals and social URLs must use the actual production origin.

### Launch assessment
Reports currently require a moderation interface and stronger abuse controls before broad promotion. Search Console ownership verification and sitemap submission require the owner's account. SEO implementation does not guarantee indexing, rankings or audience growth.
